# 验收用例（MVP）

1. P5R 窗口化前台时，≥3 分钟才可能主动说一句，且 ≤40 字 — **冒烟覆盖**
2. 对话/过场中不主动开口 — **冒烟覆盖**
3. 热键提问名词 → 识屏 → 解释 — **初版用 `--ask=`；冒烟覆盖识屏+glossary**
4. 标定日期后，当天特殊道具提醒出现，可忽略/已完成 — **冒烟覆盖**
5. 收藏攻略可回看 — **冒烟覆盖（ask 自动收藏 + --list-favorites）**
6. 同建议 30 分钟不重复 — **冒烟覆盖**
7. 默认剧透档无结局级剧透 — **冒烟覆盖（light 过滤 spoilerLevel≥2）**
8. 切走游戏后停止周期识屏与主动开口 — **冒烟覆盖**
